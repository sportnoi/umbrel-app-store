# Gallery images

`umbrel-app.yml` lists `1.jpg`, `2.jpg`, `3.jpg`. Drop real screenshots here with
exactly those names — umbrelOS shows them on the app's store page.

Guidelines used by Umbrel apps:

- **Format:** JPEG (`.jpg`), not PNG
- **Aspect ratio:** 16:9
- **Size:** 1920×1080 (1280×720 is acceptable)
- **Content:** the actual app UI, no browser chrome, no device frames

Suggested three shots for Finance Casa:

1. Dashboard — net worth chart plus account balances
2. Transactions list with categorisation
3. Budgets / monthly spend report

Until real images are added the store page will show broken thumbnails, which is
cosmetic only and does not affect installation.
